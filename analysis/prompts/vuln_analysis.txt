You are a senior application security engineer. You have been given the deduplicated findings from an automated OWASP ZAP scan of a web application. Your task is to produce a clear, actionable security analysis report.

The findings are provided below as JSON. Each entry represents a unique vulnerability type with a list of affected URLs.

<findings>
{findings}
</findings>

Produce a structured report using the following format. Use Markdown headings and formatting throughout.

---

## Executive Summary

Provide a 3–5 sentence overview of the application's overall security posture based on the findings. Highlight the most critical issues and any patterns you observe.

---

## Vulnerability Analysis

For each unique vulnerability found, include a section with the following structure:

### [Vulnerability Name]

- **Risk Level:** (High / Medium / Low / Informational)
- **Affected URLs:**
  - List each affected URL

**What it is:**
Explain the vulnerability in plain language. Assume the reader is a developer, not a security expert.

**Potential Impact:**
Describe what an attacker could do if they exploit this vulnerability. Be specific and realistic.

**Remediation:**
Provide concrete, actionable steps to fix the issue. Where relevant, include a short code example showing the vulnerable pattern and the corrected version.

---

## Remediation Priority

Provide a prioritized action list — ordered from most to least urgent — summarizing what the development team should fix first and why.

---

## Conclusion

A brief closing statement on the overall risk level and recommended next steps.
